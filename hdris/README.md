# HDRI Directory readme

## How to add HDRI backgrounds
To add HDRI files to the project, place them inside the `hdri_files` directory.
Make sure that they all end in .hdr\

IMPORTANT FOR BUILDS:\
All files need to be imported as `Keep File (exported as is)`\
Click .hdr file > Import > Import As: > Keep File (exported as is)

## Where to find HDRIs?
A good source is [https://polyhaven.com/hdris](https://polyhaven.com/hdris)

## Why aren't any HDRIs included by default?
To keep the project size manageable, big binary files have been excluded.
This includes HDRI files.
